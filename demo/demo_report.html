Scoring and reproducibility
The recorded protocol, command definitions, and file fingerprints identify exactly what this comparison evaluates.


Relative performance
Scoring rule
Each feasible run receives reference cost / run cost, capped at 1. A failed, missing, invalid or timed-out run receives 0. A zero reference gives 1 only to a zero-cost feasible solution. All scheduled runs remain in the denominator. The ranking mark is eight times the mean score.
References use participating methods only. A method labelled “baseline” or “comparison” does not change the grades. Shared scores within the recorded tolerance share a rank.
The observed reference is not a proven optimum. Scores depend on this comparison set and should be read with the experimental protocol.
Experimental conditions
Execution protocol
The scorer recomputes distances from the instance and checks customer coverage, trip capacity, and satellite consistency before accepting a result.
